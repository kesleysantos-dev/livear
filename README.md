# LiveAr — Site institucional

Landing page da **LiveAr**, empresa de ar-condicionado (instalação, manutenção, higienização, venda e peças).

## Recursos
- Hero com vídeo em loop infinito (~15s) e efeito parallax
- Animações de entrada no scroll, contadores, cards com tilt 3D, botões magnéticos e neve animada no hero
- Carrossel infinito de posts do Instagram (oculto até receber os posts da marca)
- Quiz interativo de manutenção e formulário de orçamento que abre o WhatsApp
- Layout responsivo e suporte a `prefers-reduced-motion`

## Rodando localmente
Site estático (HTML, CSS e JS puro). Basta abrir o `index.html` ou servir a pasta:

```bash
python -m http.server 8000
```

> Os dados de redes sociais, números e depoimentos são genéricos (placeholder).
> Vídeo do hero: [Mixkit](https://mixkit.co/) (licença gratuita).
